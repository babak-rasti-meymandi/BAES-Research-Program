## Assignment rule for new work

Before starting a new project:
1. identify its primary purpose and confidentiality level;
2. check whether it belongs in an existing bounded project;
3. otherwise place its program-level protocol, records, and outputs in this repository;
4. if it requires private working material, keep that material in an already existing private repository with appropriate access controls;
5. link related projects rather than copying their records;
6. do not create a new repository.

If no existing repository appears suitable, pause and ask the Founder to decide how to organize the work within the existing repository set. This does not authorize creating another repository.

## Root-level future-research records

The numbered files `997-...`, `998-...`, `999-af-colleague.md`, and `999-future-researches-index.md` remain at the repository root as planning/index records. They are not moved or deleted when project workspaces are created. A project workspace does not imply that the corresponding research has started or been completed.
