## Track lifecycle

1. Create or update a track brief.
2. Check overlap with existing projects and prior work.
3. Define a protocol and source boundary.
4. Obtain Founder approval.
5. Conduct research and preserve working records.
6. Review limitations and counterevidence.
7. Produce a bounded report and update the program registry.

A track may be placed in an existing project repository if its primary artifacts are specific to that project. The program repository should link to those artifacts rather than duplicate them.
